DyBro is an IoT-based productivity device built using ESP32 that applies the Pomodoro technique through a combination of timers, sensors, and real-time feedback.

The project explores how embedded systems can support focus and work discipline by translating abstract productivity concepts into physical interactions.

## Overview

DyBro is designed as a smart desk companion rather than a traditional software application. It operates independently, providing visual, auditory, and sensor-based cues to guide users through focused work sessions and breaks.

By shifting productivity feedback from screens to physical signals, DyBro aims to reduce distraction while maintaining awareness of time and progress.

## System Design

The device is powered by an ESP32 microcontroller and integrates environmental sensors, LEDs, buttons, and a buzzer. Communication is handled through WiFi and MQTT, enabling real-time data exchange and system control.

The logic is structured around session states, allowing the device to transition naturally between focus, break, and idle modes.

## Technology

DyBro is developed using C++ on the Arduino framework and deployed on ESP32 hardware. It leverages WiFi connectivity, MQTT messaging, and sensor-driven input to create a responsive embedded system.

## Purpose

This project demonstrates practical skills in embedded programming, IoT communication, and system-level thinking. DyBro focuses on reliability, state management, and meaningful hardware–software interaction.

## Future

Future iterations may include mobile dashboard integration, data logging, adaptive session timing, and deeper environmental awareness.
